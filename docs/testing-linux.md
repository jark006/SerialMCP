## 覆盖范围

- Shell：中文、引号、多行、无末尾换行、准确退出码、最长 64000 字符输入、显式输入重定向、默认 EOF、printf 函数/eval 别名和自定义 PATH。
- 执行状态：短暂静默不提前结束命令，超时后继续读取，不重放有副作用的命令，迟到标记不干扰下一次请求。
- 字节与输出：全 256 种字节值、NUL/非法 UTF-8 的 hex 保留、小块读取和模式切换、取消后延迟输出、UTF-8 分页及缓存淘汰。
- 并发与连接：同端口 busy 拒绝、长操作期间 ping/status 可用、取消等待、关闭重开和软件重连。
- 文件：四协议往返，X/YMODEM 额外 CRC 请求，缺失源文件、多文件拒绝、本地落盘失败及竞态、真实中断、手动握手和传输后立即执行下一条命令。

常规文件载荷为全部 256 种字节值重复组成的 4099 字节数据，SHA-256 为 `ed364c9d1fb40422180e962a3e45a07b812ab8da9b901ac85b05512bde19bb2d`。

| 协议 | 原始长度 | 常规往返接收长度 | 核对结果 |
| --- | ---: | ---: | --- |
| ZMODEM | 4099 | 4099 | 完全一致，板端 MD5 一致 |
| YMODEM | 4099 | 4099 | 完全一致，板端 MD5 一致 |
| XMODEM | 4099 | 4224 | 原始内容一致，额外尾部全为 0x1A |
| XMODEM-1K | 4099 | 4224 | 原始内容一致，额外尾部全为 0x1A |

文件矩阵对四协议各验证 0、1、127、128、129、1023、1024、1025、32769、65537 字节，共 **40 组往返、80 次文件调用**。非空文件末尾包含真实 `0x1A`；Y/ZMODEM 必须完全等长，XMODEM 只允许已知原始长度之后的填充。

## 收尾与边界

测试使用唯一 `/tmp` 目录；结束后清理测试文件、恢复 PATH/cwd，系统 lrz/lsz 仍为 0755，正常 MCP 的串口连接已恢复。初版矩阵曾因接收目录设置错误误放一个空文件，已清理并修正脚本，未计为服务缺陷；细节保留在历史记录。

上述结论适用于表中的设备与软件组合。软件重连不等同于物理热插拔；本轮没有操作 DTR/RTS、发送 break、复位或模拟物理断电，也没有验证其他 Bootloader。64 MiB 是服务上限，本轮文件矩阵最大为 65537 字节，不能据此宣称整个上限范围均已实测。
